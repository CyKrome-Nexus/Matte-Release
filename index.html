One editor

From raw capture to something you'd post.

Everything a screenshot needs before it goes into a doc, a deck, a ticket or a launch post, in one window that opens the moment you capture.

Hotkey capture

Region, window or full screen through your system's own capture UI. Record your own shortcuts; Matte waits in the tray so they work with the window closed.

Backgrounds

Gradients, solid colours or your own image. Start from Clean, Midnight, Aurora, Soft, Sunset, Paper or Glass, and save the looks you reuse as presets.

Layout

Padding, inset, corner radius and shadow, with Auto Balance to centre the shot by optical weight instead of by pixels.

Sizes that fit

Auto, 1:1, 4:3, 16:9 and 9:16, or the exact dimensions for X, LinkedIn, Instagram, Facebook and YouTube.

Annotate

Arrows, rectangles, circles and text, with thickness, opacity and size you can tune per tool.

Blur & redact

Blur or black out anything sensitive. Both are flattened into the exported pixels, so nothing hidden survives in the file you share.

Finds what to hide

On macOS, Apple Vision reads the image on-device and suggests emails, card numbers, IP addresses, API keys and phone numbers to redact. You review every one.

Export

PNG, JPEG or WebP at the scale you pick, named by your own pattern: {name}, {date}, {time}, {preset}, {size}.

Copy & Save

Optionally copy every capture to the clipboard and save it to your folder in one go. A repeated filename gets a number, never an overwrite.

Local-first

Your screenshots never leave your machine.

Screenshots are full of things that aren't yours to share. Matte is a native Tauri app that does all of its work on your computer, so the only copy that goes anywhere is the one you export.

  • ✓No upload, no cloud library. Captures, history and presets stay on your disk until you delete them.
  • ✓Text recognition runs on-device, through Apple Vision on macOS. No image is sent to a server to be read.
  • ✓Redaction changes pixels. The exported file has no layer underneath to peel back.
  • ✓No account needed to capture, edit or export.

Three steps

Capture. Frame. Share.

Set it up once, then the whole thing is a keystroke and a click.

01 · CAPTURE

Press your hotkey

Pick a region, a window or the screen. Matte hides itself, captures, and opens the result in the editor.

02 · FRAME

Make it presentable

With auto-beautify on, your default preset is already applied. Adjust the background, add an arrow, redact the email in the corner.

03 · SHARE

Copy or export

Paste it straight into a message, or export the exact size and format the destination wants.

Good to know

How capture works on each system.

Matte uses each operating system's own capture tools rather than drawing its own overlay:

macOS · asks for Screen Recording access Windows · region & window via Snipping Tool Linux · needs gnome-screenshot Text recognition · macOS only for now Any system · import an existing image
Get it

Download Matte

Run one command in your terminal to install Matte on macOS or Linux, or download the Windows installer from the latest release.

bash
curl -fsSL https://github.com/CyKrome-Nexus/Matte-Release/releases/latest/download/install-mac.sh | bash
✓ Installs into /Applications ✓ Clears Gatekeeper quarantine ✓ Apple Silicon & Intel native

The terminal installer is the preferred path until Matte is signed with an Apple Developer ID. On first capture, macOS asks you to allow Screen Recording for Matte.

bash
curl -fsSL https://github.com/CyKrome-Nexus/Matte-Release/releases/latest/download/install-linux.sh | bash
✓ Installs the AppImage to ~/.local/share ✓ Desktop menu entry ✓ Adds a matte command

Capture uses gnome-screenshot; install it from your distribution's packages if it isn't there already.
